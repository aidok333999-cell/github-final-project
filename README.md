# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest using a principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

- **Principal (P):** Initial amount of money.
- **Rate (R):** Annual interest rate in percent.
- **Time (T):** Duration in years.

## Requirements

- Bash shell
- Basic command-line environment

## How to Run

1. Clone this repository.
2. Open a terminal in the project directory.
3. Run `bash simple-interest.sh`.
4. Enter the principal amount, annual interest rate, and time period when prompted.

## Example

For a principal of 1000, annual interest rate of 5%, and time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = **100**
